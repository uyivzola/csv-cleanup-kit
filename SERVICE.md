# Custom CSV cleanup

## $300 standard package

Clean a defined batch of numeric CSV exports while preserving the original column names and order. The standard scope covers up to 10 files with the same schema and up to 100,000 total rows.

The package includes:

- Agreed numeric-format normalization, with explicit decimal and thousands separators.
- Removal of genuinely empty rows and duplicates under an agreed rule.
- Cleaned copies, a per-file change log, and a reproducible local script.
- A separate report for ambiguous values rather than guessed corrections.
- One correction round for results that do not meet the agreed rules.

Leading-zero identifiers remain text. Empty values are not silently converted to zero. Original source files remain unchanged.

**Delivery estimate:** one business day after scope, representative samples and complete rules are agreed. File size, encoding and malformed input can affect the scope. Database migration, fuzzy entity matching, new business calculations and production imports are separate work.

**Acceptance:** preserved column structure; reconciled row counts; documented removed/changed rows; agreed numeric totals reconciled; ambiguous records identified; and a repeatable run. The accompanying public tool is a demonstration of the approach, not a claim that a customer's files have already been processed.
